# What are the advantages of open source software?

## Using Open Source to the most


Open Source Software (OSS) works with open source code which is a space for users to access it through an ordinary computer, it is accessible for usage with no specific physical requirements such as extensive hardware or any specialized device. 

## But how to leverage this?

- OSS is a source code developed and maintained through open collaboration. Anyone can use, examine, alter and redistribute it as they see fit (Susnjara & Smalley, 2021)

- It is not a “one person work” which means that any user who wants to develop an idea does not require initial expert abilities, since the space allows other users with more experienced skills to interact and take the initiative to develop it. 

- An idea can become a project, and for that to think more about the things that do not work initially and then fixing them is possible since the collaboration of other users is what maintains the space developing.


### Beyond the limits

OSS has become an opportunity to create a community where helping to fix errors opens up to collaborate, include and create constant updates. 

People with different advanced expertise and diverse skills can contribute for mutual projects. In addition, this gives the possibility for multidisciplinary knowledge in business, engineering, architecture, academia etc. to be exchanged.
